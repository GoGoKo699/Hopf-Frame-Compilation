## 1. Destination, frontier and components

The destination is optimal worst-case T-depth for the prescribed complete
Hopf differential frame under the original simultaneous budgets. The
count package is settled under its stated hypotheses. R96 remains the
strongest unconditional general upper law, for every integer
$`n\ge1,L\ge6`$, with $`N=2^n`$:

```math
T=O(\sqrt{NL}+L+NL/b),\qquad G=O(NL),\qquad
D_T=O(NL/b^2+L+\log_2(n+2)).
```

One clean qubit suffices at $`b\ge17(L+n+7)`$ for real frames and
$`b\ge17(L+n+8)`$ for prescribed complex magnitude frames, with error
at most $`2^{-L}`$. The full initialized-isometry contract retains every
logical column, literal signs and phases, singular and zero coefficients,
arbitrary dirty inputs and external references, actual inverses, leakage
and complete work return. Every source, query, control, recovery and
inverse is charged. No clean copy of an address is supplied.

The count lower bound divided by the physical layer capacity
$`n+b+1`$ gives the inherited width-dependent depth lower bound; at the
literal widths it includes $`\Omega(NL/b^2)`$. Thus that contribution
is already matched when it dominates the additive upper terms, where
the eligible interval is nonempty. The large-width additive depth remains
unresolved, particularly fixed L and $`b=\Theta(\sqrt N)`$.
R79 remains selected Result D. R97 remains a bounded-outer-misalignment
obstruction; unrestricted one-clean four-layer rigidity and growing
unrestricted lower bounds are open.

Useful components include the read-only degree bounds, conditional
six-layer source transport, completed structured inverse query, and paired
permutation wrappers. Their hypotheses are not general-model invariants.
The source inverse-residual question, even if answered positively for
every native three-band C3 source, would still leave non-C3 prefixes,
address mixing, one-clean compression and growing-depth robustness.

Previously resolved questions stay closed: one-clean optimal count,
R96's all-precision upper law, general zero-clean read-only five-layer
degree 14, the specified six-layer Pauli-comparison bound, the completed
logarithmic-depth structured inverse query, and arbitrary-table
inverse-entry representations. Old next-step passages are historical.

## 2. First unpaid steps and the change of mechanism

On the lower side, complete return does not imply source-wide C3 or
inverse-Clifford coverage. The new exact six-slot example has all slots
nonempty and full word identity, but its specified source is THTHT. Its
exact Pauli domains are zero, every nonzero residual inverse Pauli image
is non-Clifford, and its actual comparison family is only identity.
This disproves the unsupported inference, not a general lower bound.
The fair simplified baseline has zero gates.

On the constructive side, arbitrary-table inverse-entry representation
is already available. Loading into a dirty coefficient array leaves an
unknown mask. Generic completed inversion exceeds the count/work budget;
the completed interpolation repair pays repeated evaluations and loses
to the direct baseline. Another representation identity alone cannot
change the complete-circuit frontier.

The chosen question was therefore: **does R98 actually need gatewise
read-only addresses, or only exact return of the address at each complete
query boundary?** The first use of the stronger premise was parallel
execution of separate queries sharing address wires. Arbitrary internal
address changes invalidate that schedule. Sequentializing every instance
would restore correctness but multiply the additive depth by their number.

A first batching attempt also fails: individually short ragged addresses
can have a much larger union. The replacement packs only the selected
address into fixed slots, using a paired permutation, then performs one
joint query and the actual inverse layout. Unselected common-bank
positions use one multi-output query on their genuine input union.

## 3. Supported result and complete ledger

R98 now accepts an exact zero-clean query with arbitrary internal native
address operations, provided its completed full-space action is

```math
|x,z,w\rangle\longmapsto|x,z\mathbin\oplus f(x),w\rangle
```

with literal phase one, arbitrary outputs/helpers and references, and
the same simultaneous bounds, for all a,q and allowed B:

```math
Q=2^a,\quad B\ge C_Q(a+2),\quad
T=O(\sqrt{Qq}+Qq/B),\quad G=O(Qq),\quad
D_T=O(d(a)+Qq/B^2).
```

For a k-bit selector and a w-site local address union, selected packing
costs $`O(2^k w)`$ T gates, Cliffords and extra dirty work, including
the paired array, with depth $`O(\log(k+2))`$. It uses one long query
on the common prefix, the longest selected subset and the selector.
Outputs are disjoint from every possible address subset. All physical
selector patterns retain their prescribed table, including malformed
metadata. The paired array is excluded from the body and all anchors.
Completed selector return suffices for its exact cancellation, even when
individual native query gates change that selector.

In each early stage the actual long address stays below
$`n-r+C\chi`$; packing counts/work are $`2^{O(\chi)}`$ and depth is
$`O(\log(\chi+2))`$. A constant number of completed queries replaces
the former parallel positions, so no multiplicity multiplies d(n).
The enlarged protected margin absorbs the table/output factors, and
the standalone arrays fit simultaneously in R98's wide branch. Narrow
and small cases retain R96. Exact macro replacement preserves the old
sources, their actual inverses and every error/leakage estimate.

Consequently the same conditional complete-frame conclusion holds:

```math
T=O_L(\sqrt N+N/b),\qquad G=O_L(N),\qquad
D_T=O_L(N/b^2+d(2n+10)+\log_2\log_2(n+4)),
```

at the original one-clean widths and full error $`2^{-L}`$.
This is a genuine weakening of a sufficient hypothesis. It does not
prove a faster arbitrary-table query, improve R96 unconditionally,
convert arbitrary queries into read-only circuits, or extend read-only
lower bounds to arbitrary address mixing.

## 4. Pause and concrete resumption

The next main question is to construct a **completed restored-address
arbitrary-table query** with $`d(a)=o(\log(a+2))`$ and the displayed
simultaneous budgets. Address mixing is now admissible in that search;
paying to remove it is unnecessary for R98. A concrete mechanism test is
to fuse table-specific coefficient access and inverse-entry extraction
into one returned native word, rather than invoke the generic full inverse
oracle. The first unpaid operation is removal or coherent cancellation
of the dirty coefficient mask within the square-root T budget and linear
Clifford budget, with no repeated-source depth loss.

Any such candidate must beat the fairly simplified R91 baseline and
return every address/output/helper column with literal phase. The current
structured inverse query and its affine representation alone do not meet
this test. Alternatively, a lower-bound parameter must survive arbitrary
Clifford interlayers and alternative native representations before it
can feed the unrestricted two-call frame reduction. Exhausting a source
subclass or a particular extraction scheme does not retire either route.
